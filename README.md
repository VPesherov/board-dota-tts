# Линии и Троны — файлы для Tabletop Simulator

Картинки и 3D-модели для стола «Линии и Троны» в Tabletop Simulator. Tabletop Simulator скачивает их по ссылкам отсюда.

Файлы собираются автоматически. Вручную их не править.

## Как поиграть

1. Скачайте `BoardDota.json` и `BoardDota.png` (кнопка Download на странице файла).
2. Положите оба файла в `Документы\My Games\Tabletop Simulator\Saves`.
3. В Tabletop Simulator: **Create → Multiplayer** (или Singleplayer) → **Games → Save & Load** → «Линии и Троны».

Правила лежат на столе слева и справа от карты. Чтобы прочитать, наведите мышь и нажмите Alt.
